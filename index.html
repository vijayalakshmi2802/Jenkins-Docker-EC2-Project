How it works

  1. Developer changes the application code.
  2. Code is pushed to GitHub.
  3. GitHub Webhook triggers Jenkins.
  4. Jenkins reads the Jenkinsfile.
  5. Docker image is built automatically.
  6. The old container is replaced with the new version.
  7. The updated application is deployed on AWS EC2.
